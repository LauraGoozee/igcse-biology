Exam answer · near object
  1. The ciliary muscles contract.
  2. The suspensory ligaments become slack (loose).
  3. The lens becomes thicker (more convex).
  4. Light is refracted more, so it is focused on the retina.
Exam answer · distant object
  1. The ciliary muscles relax.
  2. The suspensory ligaments become taut (pulled tight).
  3. The lens is pulled thinner (less convex).
  4. Light is refracted less, so it is focused on the retina.

Circular muscles form rings around the pupil. Radial muscles run outwards like the spokes of a wheel.

Exam answer · bright light
  1. The circular muscles contract.
  2. The radial muscles relax.
  3. The pupil constricts (gets smaller).
  4. Less light enters the eye, so the retina is not damaged.
Exam answer · dim light
  1. The radial muscles contract.
  2. The circular muscles relax.
  3. The pupil dilates (gets wider).
  4. More light enters the eye, so we can see better.
