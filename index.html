How they’re built

Hand-coded

Each page is a single self-contained HTML file using SVG and JavaScript, with no plugins or logins, so it runs on a phone, a tablet or the classroom board.

Practical first

Virtual labs follow the real method and give results with natural variation, so students still have to repeat, average and spot anomalies.

Accessible

Readable type, light and dark modes, labels that can be hidden for self-testing, and animations that can be paused or stepped through.

Designed and built by Laura.

These are independent teaching resources aligned to the Pearson Edexcel International GCSE and International A Level Biology specifications. They are not produced or endorsed by Pearson. Results in the virtual practicals are simulated.
